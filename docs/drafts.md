# 撤销与本机草稿

「撤销」「重做」各最多保留 30 步，刷新后重新开始。写音、歌词（含连音片段）、表情、移调、曲名、速度、拍号、谱号，以及第二声部的增删和清空，都按整首谱恢复；相关的键盘移调音区一起恢复。撤销后继续改谱，会清掉重做分支。切换正在写的声部、乐器、音域颜色和打印布局不进谱面历史。

页面快捷键为 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z。输入框内保留浏览器自己的文字撤销；要撤销谱面可点按钮。

## 自动保存

沿用 `puxian-score-v1`，停下操作 400 毫秒后保存当前谱、乐器、音域颜色、活动声部和节拍器；刷新恢复最近一次自动保存。旧版单份存档可以直接读取。打印布局仍是界面设置。

「本机草稿历史」另存最近 20 个不同谱面版本，按曲名和本地时间列出。编辑提交前先留住原谱，停下后再存当前谱；加载例子、清空、导入、恢复历史也经过这一入口，尚未等到自动保存的原谱不会被直接覆盖。连续输入的中间版本也可能占用名额，超过上限从最旧的开始淘汰。可手动保存当前草稿。

整个历史 JSON 最多 1,000,000 个 UTF-16 单元（约 2 MiB），超出时淘汰最旧版本；单份过大则保留原有存档并提示失败。浏览器禁止存储或空间不足时会提示，请导出文件备份。

恢复草稿只恢复谱面，不改变当前乐器等偏好，可以撤销。歌词、表情、两个声部均原样存储，不经过文件转换；MusicXML、MIDI、打印、PNG、SVG 继续使用同一份 Score。

## 删除与隐私

删除与当前谱完全相同的单份草稿时，也会移除「继续上次草稿」存档，并暂停自动保存，避免返回首页后重新出现；屏幕上的谱仍保留，重新编辑或手动保存后恢复存储。

可删除单份草稿，或「删除全部本机存档」（包括旧版自动保存）。全部删除后，未完成的自动保存不会立即把存档写回来；下次改谱或手动保存才继续存储。删除不清空屏幕上的谱，也不清掉内存中的撤销栈。若要退出并清除本机记录，删除后直接关闭页面。

数据只在当前浏览器的 localStorage，没有服务器、账号同步或长期备份。清除浏览器数据也会删除草稿。需要长期留存请导出文件。
