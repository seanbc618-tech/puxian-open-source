# 练琴记录（第 10 轮，吸收 Yousician「Activity / Streaks」思路）

来源（只取功能思路）：https://support.yousician.com/hc/en-us/articles/201558312-How-to-navigate-in-Yousician
（每日目标可按分钟设，按天/周看练习；Streaks 看连续练习）。

## 用户能看到的
- 「练习」面板底部多了「练琴记录」：今天练了多久、离每日目标还差几分钟（进度条），最近 7 天的小柱状图，以及连续练习天数。
- 每日目标可选：不设、5、10、15、20、30、45、60 分钟（默认 10）。当天达标后进度条和那天的柱子变绿。
- 播放乐谱或「等你弹」时自动计时，停下后记入；播放中卡片显示「正在计时，停下后记入」。关页或切到后台时也会先把已练的记下来。
- 当天练满 1 分钟算打卡。今天还没练时，连续天数从昨天往回数，不会算断。

## 规则（src/lib/music/practice-log.ts，纯函数 + 单测）
- 只存在本机 localStorage `puxian-practice-log-v1`，不写进谱子、草稿、导出或分享链接。
- 按本地日历日计，跨午夜的一段拆到两天。一次最多记 3 小时，单日最多 24 小时；只保留最近 400 天。
- 坏数据丢掉：不是日期的键、非正数、不在选项里的目标。

## 同轮顺带
- 懒加载重试：首页打开编辑器、歌单，以及编辑器里的和弦指南、琴键、等你弹、混音台、练习设置、调音器、节拍器、练琴记录、和弦库，块加载失败会再试。浏览器不会缓存失败的模块请求，所以重试会真的重新下载。首页那两处直接写在代码里（`load().catch(load)`），不另起共享模块，免得多一个首屏请求。编辑器内用 `src/lib/lazy-retry.ts`，最多再试 2 次，间隔 0.6 s、1.2 s。
  首屏没变大：「继续上次草稿」按钮原来用 `&&` 条件渲染，打包时 quiet 按钮的整串类名被内联了一遍。改成三元表达式后不再内联，省出的字节够放重试代码。
- 全屏 + 和弦指南：全屏时点和弦指南不会再被当成翻页（以前点不开）。展开后最多占舞台 28 dvh（最高 240 px），超出的部分在指南里滚动。「下一屏」和跟随滚动把指南盖住的顶部扣掉（`stickyCover`），翻页不会把一行藏到指南下面。非全屏时展开最多 40 dvh（最高 320 px）。
- verify-gp5 / verify-voices 也改用 `scripts/static-server.mjs` 的 128 队列服务器。

## 验证
scripts/verify-practice-log.mjs：
- 首页的编辑器块、编辑器里的练琴记录块各断一次，都能再加载出来；
- 预置数据后检查摘要、进度条、7 天柱和目标切换；
- 播放约 2.5 s 后，今天的记录增加 2–10 s；
- 390 宽下卡片放得下；
- 全屏（指南收起和展开）一路「下一屏」到底，每个音都至少在某一屏完整露出；
- 展开的指南高度不超过上限。

# 第 11 轮：每首曲子的练琴时长与笔记（吸收 Andante 思路）

来源（只取功能思路）：https://andante.app/ 、https://apps.apple.com/us/app/andante-music-practice-journal/id1530262372
（按曲目记练习时间；练习笔记）。

- 「练琴记录」卡片多了三样：
  - 「这首曲子：累计 X · 上次 M月D日」；
  - 「这首的练习笔记」（最多 200 字，失焦就存；收起面板或换曲子时没存的也会存）；
  - 「练得最多」前 3 首（累计满 1 分钟才列）。
- 曲子按草稿 id 记（编辑器打开时就有 id），最多留最近练过的 50 首。
- 计时范围：播放乐谱、等你弹、**独立节拍器**都计入（Sean 的决定），调音器不计。节拍器在播谱时会自动停，所以不会重复计时。
- 「清空记录」要二次确认：点「确认清空」后清掉时长、连续天数和每首的笔记，每日目标保留；播放或节拍器运行中不能清空。
- 390 宽全屏：
  - 外框边距收紧；
  - 曲名只占一行（30 px）；
  - 视图切换按钮 36 px 高；
  - 翻页、自动滚、速度并成一行，隐藏「轻触左右翻页」提示（宽屏仍显示）；
  - 谱面区 523 → 646 px。

# 第 13 轮：练耳计入、拍节奏计入

- 听音练耳计入每天时长和连续天数（Sean 的决定）。
  - 不记到当前曲子：练耳练的是调里的级数，不是这首曲子。卡片上单列「听音练耳累计 X（算进每天时长，不记到曲子）」。
  - 计时从听题或作答开始，最后一次操作后 1 分钟（`EAR_IDLE_MS`）没动就停；收起练耳或关掉练习面板立即停。
  - 播谱、节拍器或拍节奏同时在跑时，这段算曲子，不重复记。状态一变（曲子 ↔ 练耳）就分段记账。
- 拍节奏运行时计入当前曲子。
- 「清空记录」也清掉练耳时长。
