# 调音器与独立节拍器

借鉴 GuitarTuna / Soundbrenner 一类练习工具的体验（只取功能思路，不用其代码、品牌或素材）。全部在浏览器本机运行：Web Audio + 麦克风 YIN 音高检测，无后端、无 API Key、不录音不上传。

## 调音器（「听写与音频」→ 调音器）
- 点「调音器」才加载（懒加载 `practice-tools` 分块），点「开始调音」才请求麦克风；「停止调音」或「收起调音器」立即释放麦克风。
- 显示最近音名（如 A2）、按本曲调号换算的简谱级数（小调按关系大调的首调唱名）、频率 Hz、音分偏差；±50 音分指针，±5 音分内变绿。
- 乐器预设：自由 / 吉他 EADGBE / 尤克里里 GCEA / 小提琴 GDAE。选了乐器时按最近的空弦计算偏差，提示「第 n 弦 X：调高 / 调低 / 已准」。
- 标准音 A4 可在 430–450 Hz 间调。
- 帧间取最近 5 帧的中位数，指针更稳。纯函数在 `src/lib/music/tuner.ts`，有单元测试。

## 独立节拍器（「练习」→ 独立节拍器）
- 不播谱也能用；有自己的音频上下文，按 25 ms 间隔、120 ms 预排（lookahead）排点击，不受界面卡顿影响。
- 30–240 BPM；「点按测速」取最近最多 8 个间隔的中位数，停顿超过 2 秒重新计。
- 每小节 1–12 拍（默认跟本曲拍号）；细分：不细分 / 八分 / 三连音 / 十六分。
- 每拍点按在「重 / 普通 / 静音」间切换；当前拍高亮。
- 开始播放乐谱时自动停止，避免两个节拍叠在一起。
- 纯函数在 `src/lib/music/metronome.ts`，有单元测试。

## 混音即时生效
播放中拖音量、点静音或独奏立即生效（每声部一条修正增益总线）。被静音的声部重新打开，以及音色、声像，在下次播放生效；循环播放时在下一遍生效。

## 验证
`scripts/verify-practice-tools.mjs`（由 `verify:static` 调用）：用本机振荡器冒充麦克风，检查弦名/音分/简谱级数、准音变绿、麦克风释放；节拍器点按测速、静音拍、播放乐谱时自动停；播放中改音量和静音会作用到已排的音；320px 不溢出；功能栏仍为 8 项。

## 节拍器练习模式（r17）

借鉴 Pro Metronome 的「静音小节」（gap click）和速度训练（tempo trainer），只取思路，没有用它的代码、名称或素材。逻辑在 `src/lib/music/metronome.ts`（`barMuted`、`rampBpm`、`trainerTicks`），测试见 `metronome-trainer.test.ts`。

- **静音小节**：响 2 停 1、响 1 停 1、响 2 停 2、响 4 停 4。停的小节不发声，拍位灯照走，状态行写「静音中，心里继续数」，用来练内心节拍。运行中切换立即生效。
- **自动加速**：每 2 小节加 2、每 4 小节加 4、每 8 小节加 5，加到目标速度（比当前快 10～60）为止，到了写「已到目标速度」。每小节自己的速度直接算进排程，中途不重启音频。改加速设置会从头重来。
- 两项都默认「不用」，不开时与原来的节拍器完全一致（测试里逐拍比对）。

## 段落循环：每遍后停、练几遍（r18）

借鉴 Amazing Slow Downer 的「循环之间停顿」和「重复 N 次」，只取思路，没有用它的代码、名称或素材。逻辑在 `src/lib/music/loop-pause.ts`（`loopClock`、`fullPasses`、`passStart`），测试见 `loop-pause.test.ts`，浏览器验收 `scripts/verify-loop-pause.mjs`。

- 打开循环后才出现两项：「每遍后停」不停 / 1 / 2 / 4 秒，「练」不限 / 3 / 5 / 10 遍。每首歌各自记住，默认值不写进存档。
- 停顿里什么都不响、谱上不亮，状态行写「第 N 遍练完，停 X 秒再来。」；播放中写「第 N / 总数 遍」。练够遍数后自己停下，提示「已循环练完 N 遍。」，最后一遍后不再等停顿。
- 播放中改这两项会从循环开头重来；变速续播的那半遍算第一遍。
- 只作用于普通循环；开着「渐进加速」时仍按渐进加速的遍数走。
