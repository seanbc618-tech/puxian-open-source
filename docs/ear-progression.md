# 听和弦进行（练耳）

谱线在「练习 → 听音练耳」里，除了认级数、认音程、认和弦，还可以切到「认进行」。想法来自 Teoria 的 Harmonic Progressions：弹出一串调内和弦，按罗马数字依次点出进行，不改当前谱子。题目由本机按当前调随机生成，不用受版权的旋律。

- 范围：基础（默认，终止式）、常见（流行与 ii–V–I 等）、全部。大调与小调各有一套进行；小调的 V 用和声小调（升高导音），VII 用自然小调的大三和弦。
- 听法：柱式（默认）或分解。每个和弦都是原位，低音再低八度重复根音。
- 点够长度后自动判定；点错可「退格」，答错后清空重选，可以「再听一次」。
- 对错记在本机 `puxian-ear-progression-v1`，与认级数、认音程、认和弦的记录分开。时长仍计入听音练耳。
- 默认仍是认级数，原来的定调 + 级数、认音程、认和弦练习不变。
