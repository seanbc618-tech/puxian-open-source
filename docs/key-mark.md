# 途中转调

吸收 [MuseScore 调号](https://handbook.musescore.org/notation/notes-and-rests/key-signatures) 的思路：在选中的音或休止所在小节换调（1=X），从这一小节开头起改调。只取功能，没有用它的代码、名称、文案或素材。没有做五线谱刻调号。

## 用法

打开「写谱」，点谱上第二小节及之后的音（或休止），在「途中转调」里选调和调式，再点「设为从这小节换调」。记号落在该小节开头；简谱（屏幕和打印）会在该处标出新的「1=X」。再点「去掉此处调号」可取消，一步撤销。第一小节或全曲开头仍用「移调与乐器」里的调。选择记在谱子里（`Score.changes` 的 `key` / `mode`），会随草稿、分享和已有的 MusicXML / MIDI 导入导出一起走。

播放、MIDI、音域检查（记谱拼写）和整首移调本来就会跟随途中转调。不改写成谱时值。五线谱在该小节开头刻新调号（r40 修掉了自动换行后调号刻两遍的问题，见 docs/staff-marks.md）。

## 实现

纯函数在 `src/lib/music/key-mark.ts`（不进 score-core）。沿用已有的 `Score.changes`，不改 `isScore`。途中转调标注不改宿主高度，避免含大量转调的谱触发布局循环。
