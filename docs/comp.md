# 和弦伴奏（播放跟奏）

谱线在「写谱 → 和弦标记」里提供「播放时加伴奏」。想法来自 iReal Pro 的跟奏：按谱上已有的和弦标记，在播放时加一层简单的本地伴奏，谱面写法本身不变。

打开后，播放会在标记持续的时间内加上：

- 低音：简单拍（4/4、2/2）打在第 1、3 拍，三拍子打在第 1、3 拍；6/8 按附点四分的律动。斜线低音（如 C/G）走写下的低音。
- 柱式和弦：每个和弦进入时，以及之后每个小节正拍，轻声叠一个密集排列的柱式和弦。

没有和弦标记，或标记为 N.C. / 无，这一段不响。伴奏只走本机 Web Audio，不改谱子、不写进导出，也不占用功能栏新项目。选择记在本机 `puxian-comp-v1`。播放中开关伴奏，会从当前位置接着放。
