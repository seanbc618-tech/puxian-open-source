# ABC 导入与导出（r16）

借鉴 ABC 记谱工具（EasyABC、ABC Transcription Tools 一类）的长处：**一段纯文本就是一页五线谱，改完文本再导回**。只吸收思路，没有用这些工具的代码（它们多为 GPL）、名称或素材。实现在 `src/lib/music/abc.ts`，纯函数，测试见 `abc.test.ts`，浏览器验收见 `scripts/verify-abc.mjs`。

## 入口

- 写谱 → 「导入 123 / 番茄 / JP-Word / ABC」选 `.abc` 文件，或把 ABC 贴进文本框点「导入粘贴的文本」。会替换整谱，可撤销，导入后列出丢失清单。
- 打印与导出 → 「导出 ABC（.abc）」。按钮旁会预先写出这首导出会丢什么。

## 导入支持的子集（ABC 2.1）

| 内容 | 处理 |
| --- | --- |
| `X:` `T:` `M:`（含 `C` `C\|`）`L:`（缺省按拍号取 1/8 或 1/16）`Q:`（`1/4=120`、`3/8=80`、纯数字）`K:` | 读入；缺的字段按默认值并写进「说明」 |
| `K:` 大调、小调（`m` `min` `aeo`）、`clef=bass` | 读入 |
| `K:` 教会调式（dor phr lyd mix loc） | 按同调号的大调读入，记损失 |
| 音高 `C`…`b`、`'` `,`、`^ _ = ^^ __`（本小节内持续） | 读入 |
| 时值 `2` `/` `//` `3/2`、附点节奏 `>` `<`、连音 `(3` `(p:q:r` | 读入 |
| 和弦 `[CEG]`、休止 `z`、整小节休止 `Z4`、延音线 `-`、连线 `( )` | 读入；`x` 按休止并记损失 |
| 装饰音 `{g}`（倚音）`{/g}`（短倚音） | 只留第一个音 |
| 和弦名 `"G7"` | 读进和弦名；`"^文字"` 等注释记损失 |
| `!p! !mp! !mf! !f!`、`. !accent! !tenuto! !trill! T !arpeggio!`、`!<(! !<)! !>(! !>)!` | 读入；`pp` `ff` 等按最近的力度并记损失 |
| `\|: :\| :: [1 \|1 :\|2` | 变成反复和一二房子；放不进谱线的反复模型时整组丢弃并说明原因 |
| `!segno! !coda! !fine! !D.C.! !D.S.! !dacoda!` | 变成跳转记号，经 `jumpProblem` 检查 |
| 正文 `K:` `M:` `Q:` 与行内 `[K:] [M:] [Q:]` | 变成中途变调 / 变拍 / 变速 |
| `w:` 歌词（`-` 连字、`_` 延长、`*` 跳过、`\|` 跳到下小节） | 第一段读入，跳过休止；第二段起记损失 |
| 第一首以后的曲子、第二个及以后的 `V:` 声部、`&` 叠加声部、`W:`、`P:`、`~ H M P u v` 等其他装饰 | 记损失 |

弱起小节和 123、番茄一样在前面补休止。

## 导出

`X:1`、`T:`、`M:`、`L:1/8`、`Q:1/4=…`、`K:`（小调写成 `Dm`、`C#m` 这种升降号不超过七个的写法），每行四小节，有歌词时每行下面跟一行 `w:`。升降号按调号拼写，同一小节内只写一次；小调里升高的 3、6、7 级用升号。跨小节的音拆开并用 `-` 连起来，三个等长的三连音写成 `(3`。和弦名、力度、奏法、装饰音、渐强渐弱、连线、反复与房子、跳转记号和中途变化都会写进去。

不写进去、会在导出提示里列出的：第二个及以后的声部、指法、一个音上的多段歌词片段、落在音符中间的和弦名或变化、谱线以外的特殊时值。

## 按需加载（r17）

`abc.ts` 是单独的懒加载块：只有文件 / 粘贴内容被认成 ABC，或点「导出 ABC」时才下载（`text-formats.ts` 的 `loadAbc`，失败会重试）。识别用的 `abc-sniff.ts` 很小，留在编辑器块里。为了不让编辑器块多出共享小块，ABC 的歌词对齐与弱起补休止在 `abc.ts` 内自带一份。编辑器块回到约 332 KB（#85 时约 351 KB），首屏不变。`verify-abc.mjs` 检查粘贴 123 时不下载 ABC 块、粘贴 ABC 后才下载。
