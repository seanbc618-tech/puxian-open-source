# jianpu-ly 印刷互通（Step D）

在「打印与导出」点击「导出 jianpu-ly（.jly）」下载 UTF-8 文本。此功能仅导出 `.jly`，不在网站生成 PDF，也不替换浏览器打印。浏览器仍打印当前五线谱并保留原有分页；`.jly` 交给本机工具另排数字简谱，分页与字体由 LilyPond 决定。

## 本机生成 PDF

本机安装 Python 3、[jianpu-ly](https://github.com/ssb22/jianpu-ly) 和独立安装的 LilyPond（上游 README 列出兼容 2.20、2.22、2.24）。例如：

```sh
pipx install jianpu-ly
jianpu-ly < 曲谱.jly > 曲谱.ly
lilypond 曲谱.ly
```

也可用 `python3 /本机路径/jianpu-ly.py < 曲谱.jly > 曲谱.ly`。中文 PDF 需本机有可用的中文字体；请自行核对字体、歌词对位与分页。转换失败时 `.jly` 仍可编辑，网站的浏览器打印仍可使用。此版本未提供在线 PDF、自动安装工具或可选 CLI 助手，未捆绑上游 Python 文件或 LilyPond。

## 支持的子集

- 曲名 `title=`、大调 `1=X`、小调 `6=X`、拍号与四分音符速度 `4=bpm`。
- MIDI 整数音高的单音、升降号、逗号／撇号八度、休止 `0`、至六十四分音符（`q/s/d/h`）、附点。长音与跨小节同一音用 `-` 延续。小节由 jianpu-ly 按拍号计算。
- 第一和第二声部各自的时间线，用 `NextPart` 分开；短声部及不完整末小节补休止至共同完整小节，不改 Score。
- 延长记号写成 `\fermata`（写在对应音后面，按上游说明作用于前一个音）。渐慢/渐快写成 `^"rit."` / `^"accel."`（可带目标速度），区间结束处若没有新的 `4=bpm` 则补 `^"a tempo"`。只取 [jianpu-ly](https://github.com/ssb22/jianpu-ly) 文档里的语法思路，不复制上游代码。
- 第 1 段歌词以 `H:` 输出，休止不占歌词位，缺词音符输出空位；同一音节的连续汉字用下划线相连。分词、延长线不保留，会提示。含空格音节合并并提示。跨小节延音沿用同一个音节。

`scoreToJianpuLy(score, { instrumentShift, pitch })` 默认 `pitch: "written"`，按所选乐器的半音移调同时移动调号和音高，与 `engraveAbc(score, instrumentShift)` 及当前浏览器打印一致。`pitch: "concert"` 忽略乐器移调，导出实际音高。UI 使用当前乐器的记谱音高。简谱八度以 jianpu-ly 的中央八度为基准，不以编辑器的 `tonicOctave` 改变实际音高。小调从编辑器的 do 小调转换为 la 小调，例如 A 小调的 A4 写 `6`。

## 损失与限制

- 力度、奏法、连线、渐强渐弱、装饰音不输出，下载时中文提示；主音音高与时值保留。延长与渐快/渐慢会写出。
- 和弦、三连音及其他非二进制时值会阻止导出并提示使用 MusicXML／浏览器打印，避免静默丢音或改变节奏。
- Score 只保存两声部及 verse1；第三声部、反复、其他段歌词不在模型中，无法恢复或导出。导入时已丢失的信息无法在此再检测。界面明确列出这些限制。
- 曲名和歌词限文字、数字及常见标点；换行、引号、反斜杠等控制字符替换为空格并提示，文本不能插入 LilyPond 指令。
- 不保证与浏览器打印完全相同的视觉布局；请在正式印刷前检查本机 PDF。

转换规格参考只读快照 `b3c2bbb` 的 README 与 `jianpu-ly.py`。本项目独立实现文本适配器，没有复制上游实现代码。许可见 [第三方说明](third-party.md)。
