# Guitar Pro 5 本地导入

在「输入」选择 `.gp5`（GP5 5.00 / 5.10，最多 4 MB）。
文件解析完成后先看简谱预览和「本次导入丢失了什么」；取消不改谱，
确认才整谱替换。确认后的修改进入原有撤销历史。

保留前 16 个有音符的非打击乐声部（第 3 个起写入独立声部 extraVoices），各自的和弦、休止、附点、连音时值，
定弦/变调夹后的实际音高，以及共享速度、拍号、调号变化。
同音组整组延音线合并时值；局部延音线保留书写时值并报告重新起音风险。
扫弦近似为琶音，击弦/勾弦近似为连线，均报告专用演奏参数损失。
超过模型范围的声部、图示/文字、音色和吉他专用技法列入损失清单。
反复按书写顺序导入，不自动展开。超范围拍号拒绝导入。

解析仅使用 alphaTab 的字节解析入口，不实例化它的渲染器或播放器，
没有远程请求。版本和 MPL-2.0 文件级许可声明见 [第三方说明](third-party.md)。
自建 CC0 小样与生成器见 `src/lib/music/fixtures/gp5/`。

验证：`npm test`、`npm run typecheck`、`npm run build:static`、
`npm run verify:static`；额外 `node scripts/verify-gp5.mjs` 在 Chromium/Firefox
验证预览、取消、确认、撤销、损坏文件不覆盖草稿及无外部请求。
