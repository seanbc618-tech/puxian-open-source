# MIDI 增强量化（C）

旧 `midiToScore` 和选轨到当前声部保持原算法。新增 `previewMidiImport(bytes, title, options)`
返回临时 Score、中文 notice、hands 映射结果；不修改原始 bytes。
界面先预览误差与损失，确认后一次发布，可撤销。单轨也可选增强或旧导入。
API 可选 grid=0.25（默认十六分）或 0.125（三十二分），hands=true / "auto"。

完整局部三连音组在误差明显优于普通网格时落到 2/3、1/3、1/6 拍。
保留绝对 tick，开头休止不删，重叠截短前音而不推迟后音；同时和弦最多四音，超出计入丢弃。
短于 1/8 拍的单音，紧接较长主音时保守折叠成 grace/gracePitch；占用原先现音到主音结束的时间。
孤立短音作最小网格近似并提示。

琶音：三个及以上起音逐个上行（相邻 ≤1/8 拍、总跨度 ≤3/8 拍），最后一个起音后仍至少持续 1/4 拍、
且各音放开时间相差 ≤1/4 拍时，合成一个和弦并加琶音装饰（`ornament: "arpeggio"`），按首音落点；
错开量不计入落点偏差，notice 报"琶音 N 组"。逐个放开的快速分解和弦、只有两个起音或下行的错开不合并。
Score 只有"向上琶音"一种记号，不区分方向、速度或分手琶音；播放时在原时值内由低到高依次起音、同时收尾。

按拍号切分跨小节音和休止，总时长不累积漂移。Score 无完整 tie 模型，
相同音高序列保持等价时值，但播放/MIDI 导出会重新起音，不承诺持续发声无损。
Score 和弦共用时值；同起音不同结束的音保留原始起止时间用于误差计算，
预览逐音列出因统一时值而延长的 MIDI 音高与延长拍数，并计入最大结束偏差。
notice 汇总三连音、倚音、短音近似、截短、丢弃、琶音及最大起止偏差（四分音符拍）。
不处理速度/拍号变化图、任意复节奏或演奏踏板。

双手只接受恰好两条有音符的 track/channel：优先 RH/LH、Right/Left、右手/左手；
无明确名称时，两条音域至少间隔七个半音才自动分配。
notes=RH，voice2=LH，各自从文件零点开始；成功会替换两个声部。
空轨和鼓通道不参与。单轨、名称冲突、音域交错或额外轨均降级到所选轨（默认第一条），
中文明确提示其余轨未导入。不会把额外轨挤进和弦，也不按固定中央 C 猜单轨双手。
未做原神键位、斜杠谱、壳、D/E 或外部格式转换。
