# 第 13 轮：拍节奏（吸收 Complete Rhythm Trainer 思路）

来源（只取功能思路，不用代码、品牌、素材）：
- https://apps.apple.com/us/app/complete-rhythm-trainer/id1550799056
- https://completerhythmtrainer.com/
（读谱拍节奏练习：先给预备拍，跟着节拍器点按谱上的节奏，按每个音判定早晚并打分）

## 用户能看到的
- 练习面板新增「拍节奏（跟着节拍点按）」，懒加载，首屏不变（8 个请求 / 384,701 B）。
- 范围：设了 A-B 段落就拍那一段，否则拍前 4 小节；速度跟着当前练习速度（含渐进加速）。
- 先响一小节预备拍（重拍高音），然后节拍器继续打拍，用户在大按钮上点按（或按空格、回车），每个音点一下；休止不用点。
- 结束后显示：
  - 一行总结：「准 N · 偏早 · 偏晚 · 漏拍 · 多拍；整体偏早/偏晚 X 毫秒（或很稳），得分」；
  - 节奏对照条：竖线是谱上的音，圆点是点按（绿＝准，黄＝偏早/偏晚，红＝多拍）；
  - 每个音一格的结果（偏早/偏晚附毫秒）；
  - 「要再练：第 a、b 小节」。
- 拍节奏运行时计入这首曲子的练琴时长。

## 判定（`src/lib/music/rhythm-tap.ts`，纯函数，有单测）
- 目标：第一声部每个非休止音符的起点，按速度变化和练习速度换算成秒。
- 每个音只能配一次点按，在 ±200 ms 内取最近的；窗口不超过到相邻音的一半，所以一下不会算给两个音。
- |偏差| ≤ 70 ms 算准，其余算偏早/偏晚；没配上的音算漏拍，没配上的点按算多拍。
- 得分 =（准 + 0.5 ×（偏早+偏晚））/ 音数 × 100，每个多拍扣 5 分。
- 点按用页面时钟（事件 timeStamp），开始时和音频时钟对齐一次；判定前减去本机存的延迟补偿（第 14 轮）。
