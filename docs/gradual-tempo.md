# 渐快 / 渐慢

吸收 [MuseScore 速度记号](https://handbook.musescore.org/text/tempo-markings) 里渐快、渐慢的思路：在选中的起止音之间（或从选中音起跨若干拍、到下一个途中速度记号）标「渐慢 rit.」或「渐快 accel.」，播放时在这段里平滑变速，谱面时值不变。只取功能，没有用它的代码、名称、文案或素材。五线谱也刻：第一个音上方写 rit. / accel.，虚线延到区间最后一个音（r40，见 docs/staff-marks.md）。

## 用法

打开「写谱」，在「途中速度」下面的「渐快 / 渐慢」里：点选起止音，或从当前音起跨若干拍、到下一个途中速度，再点「渐慢 rit.」或「渐快 accel.」。可选目标速度比例或目标 ♩=；不填时，渐慢默认落到起点速度的 3/4，渐快落到 4/3，若结束处已有途中速度则沿用该速度。简谱（屏幕和打印）会画出记号文字和虚线延伸。再点「去掉此处渐变」可取消，一步撤销。

播放、节拍器和 MIDI 在区间内按这条曲线走。不改写成谱时值。全曲开头和途中突然换速仍用上面的「途中速度」或「移调与乐器」里的速度。选择记在谱子里（`gradualTempos`），会随草稿和分享走。不改 `isScore` / score-core。

标注不改宿主高度，避免《匈牙利狂想曲第二号》等含大量变速的谱触发布局循环。

## 导入导出

MusicXML 导入和导出会保留渐快 / 渐慢：写出 `<words>rit.</words>` 或 `<words>accel.</words>` 和 `<dashes>`；有目标速度且该处还没有途中速度记号时，在结束处写 `<sound tempo>`。导入时尽量还原区间和目标速度（有虚线按虚线起止，只有文字时则收到下一个途中速度或默认几拍）。这些用语不再列入「谱上文字」丢失。途中速度、途中拍号、途中转调和延长记号同样会完整读写，也不再列为丢失。

123 文本谱已经能读入行内变拍、变速、转调和延长，但还不读写渐快 / 渐慢，也没有对应导出。番茄文本谱仍把延长和 rit 等用语列入丢失。.jly 导出已带上途中调、拍和速度，暂不写延长或渐快 / 渐慢。这些请继续用 MusicXML 交换。
