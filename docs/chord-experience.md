# 和弦按法、变调夹与调内和弦

本轮体验参考（独立实现，没有引入对方代码、素材或依赖）：

- https://chordify.net/pages/chordify-toolbox/
- https://support.chordify.net/hc/en-us/articles/360002164538-How-to-use-Premium-features
- https://www.hooktheory.com/support/hookpad
- https://www.hooktheory.com/hookpad

谱面的和弦图展示当前与下一处标记；展开设置可选吉他、尤克里里、钢琴及查看全部图。吉他按低音弦至高音弦排列，尤克里里使用高 G 的 GCEA 调弦。圆圈为空弦，叉号不弹，圆点中的数字为品位；横按形状仍用逐弦落点表示。斜杠和弦展示根和弦图并提示低音。钢琴标出实际组成音。

常用形状使用内置表，其他形状在 0–5 品内穷举：必须覆盖组成音，按弦跨度不超过四品，最多四个独立落指或简单横按，优先空弦。常见 C7 指型可省略五音。不提供超出此范围的高把位；找不到按法时只列组成音。暂不解析的扩展和弦会明确提示，保留原标记。

变调夹 0–7 品仅改变弦乐器的按法；钢琴、谱面音高和本地 Web Audio 播放均保持实际音高。推荐按开放弦、按弦数量、最高品位及横按代价评分，并对高品位略加代价。它是便于尝试的建议，不代表每位演奏者的最优选择。

主/副标签可交换和弦名与级数，可选罗马或简谱数字。调内和弦使用自然大/小调，按标记位置读取 `Score.changes` 的调号；进行从所选小节起每小节一处，在现有谱尾截断，预览后才应用。已有同位置标记默认保留，勾选确认才覆盖。应用通过原有 commit/history 路径，可一次撤销。

数据仍存于原来的 `Score.chordSymbols`。按法、变调夹与标签设置仅存 `localStorage` 的 `puxian-chords:<songId>`，不进入草稿中的 Score 或导出。显示用副本不传入音频或导出路径，旧稿无需迁移。

`chord-diagrams.ts`、`chord-degrees.ts` 和对应 UI 仅由编辑器懒加载；`chord-symbol.ts` 不加入新功能，仅简化原有升降号字符串格式化以抵消新增跨块导出字节。首页预算与原来的三个 manualChunks 分组均保留。

验证包括纯函数的常用指型/调弦/组成音、变调夹评分、升降调与小调级数、换调换拍号进行、合并保护，以及浏览器的乐器切换、实际音高不变、推荐/记忆、播放跟随、预览/覆盖/撤销、390×844 琴键与练习面板至少 200px。
