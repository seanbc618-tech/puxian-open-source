# 简谱文本互通（Step E2）

谱线支持三种简谱文本格式，统一从「写谱 → 导入简谱文本」进入，也可以从 MusicXML、MIDI 导入。每次导入后，所在面板都会列出一张「本次导入丢失了什么」清单。这张清单不会自动消失，要手动收起，所以内容不会被悄悄压平。导出可做 JP-Word、123 和 ABC。

登记表在 `src/lib/music/text-formats.ts`，借鉴 Dolce `src/editor/formats.ts` 的 FormatAdapter 思路：每种格式在一处声明扩展名、编码和读写能力，导入流程是「解码 → 解析 → 诊断 → 丢失清单」。判断格式时先看扩展名；`.txt` 和其他扩展名再看内容（含 `irealb://` 链接判为 iReal Pro，UTF-16 BOM 判为 JP-Word，有 `K:` 头且正文字母音符多于数字音符判为 ABC，`%123` 或 `K:` / `调：` 判为 123，番茄头字段判为番茄），认不出就拒绝。文件上限 2 MB。导入失败时，现有谱不会改动。

谱线没有弱起小节的概念。123 和番茄导入时，如果第一小节不满一小节，会在前面补休止，让后面的小节线对齐，并在「说明」里写明补了几拍。

导入结果分两类：
- `losses`：原文件里有、谱线没有保留的内容，进入清单。
- `notes`：文件缺字段时采用的默认值，显示为清单里的「说明」。

## 编码

| 格式 | 扩展名 | 读 | 写 | 编码 |
| --- | --- | --- | --- | --- |
| JP-Word | `.jpwabc` | ✓ | ✓ | UTF-16LE + BOM（`FF FE`），CRLF；导入不回退到 UTF-8 |
| 123 简谱 | `.123` | ✓ | ✓ | UTF-8，可带 BOM；UTF-16 和非法 UTF-8 一律拒绝 |
| 番茄简谱 | `.jps` `.fq` `.pu` | ✓ | — | UTF-8，可带 BOM；UTF-16 和非法 UTF-8 一律拒绝 |
| ABC | `.abc` | ✓ | ✓ | UTF-8，可带 BOM；只读第一首的第一个声部，见 [abc.md](abc.md) |
| iReal Pro 和弦谱 | `.html` / 粘贴链接 | ✓ | — | `irealb://` 链接或 iReal 导出的歌单网页；取第一首，声部 1 写成柱式和弦，见 [ireal.md](ireal.md) |

## JP-Word 导出（`jpwabc-export.ts`）

导出结果用谱线自己的 JP-Word 导入器读回，测试检查音高、时值、第 1 段歌词以及调、拍、速度是否一致（外部文本 → Score → 外部文本 → Score）。不保证字节完全相同。

- 调号写成 JP-Word 的拼法，例如 `1=bD`、`1=#F`。临时升降号逐个写出，因为 JP-Word 导入器不会在小节内沿用。
- 时值从 `---`（四拍）到 `____`（十六分之一拍），用附点组合。其他长度会拆成同音，并在清单里提示。
- 每行 24 个记号。每个小节边界写一条 `|`，结尾写 `|]`。
- 歌词写成一行 `W1:`。休止和没有歌词的音写 `/`，多字歌词用 `{}` 包起来，末尾多余的 `/` 省略。

**写不进去、会在导出前列出的内容：** 第二声部、曲中变调/变拍/变速、和弦标记、和弦（只保留最高音）、力度与渐强渐弱、奏法、装饰音、圆滑线、连字符和延长线、被拆开的长音。小调按关系大调写出，并附说明。

**拒绝导出（现有谱不变）：** 连音组（JP-Word 导入器也会拒绝）、写不出的时值、空谱、超出范围的拍号或速度。

## 123 简谱导入（`j123-import.ts`）

规格来自 Dolce `docs/格式/123格式.md`，本仓独立实现。

| 内容 | 结果 |
| --- | --- |
| 头字段 `X T C K M Q V w`、中文别名（标题／调／拍号／速度…）、全角冒号 | 保留标题、调、拍、速度；副标题、词曲署名列入丢失 |
| `K:1=bE` `K:Em` `K:6=E` `K:A minor` | 小调写成 mode=minor，key 取主音；其他调式按 do 调读入，并附说明 |
| `1–7`、`0` 休止、`x` 隐藏休止、`#` `b` `n`、`'` `,` | 保留。升降号在同一小节内按级数沿用，B 调无点主音在第三八度 |
| `_` 减半、`.` 附点、`-` 延长、`(3:` 等连音 | 保留 |
| `( )` 圆滑线；同音 `~` 或圆滑线当作延音线 | 圆滑线保留；延音线合并成一个长音，因为谱线没有单独的连音线概念 |
| `[135]` 和弦 | 保留，最多 8 个音 |
| `!mf!`、`!accent!`／`!zy!`、`!staccato!`／`!dy!`、`!tenuto!`／`!bc!`、`!tr!`、`{3}` 倚音 | 映射为力度、奏法、装饰音；其他记号列入丢失 |
| `[K:]` `[M:]` `[Q:]` 行内变调/变拍/变速 | 写进 changes |
| `!fermata!` `!yc!` `!延长!` | 写进 fermatas，不再列入丢失 |
| `"^rit."` `"^accel."` `"^rall."` 与 `!rit!` / `!accel!`，结束处 `"^a tempo"` 或下一个途中速度 | 写进 gradualTempos，不再列入「谱上文字注记」 |
| `V:1` `V:2`、小节内 `&` | 进 voice2；第三声部起列入丢失 |
| `w:` 歌词 | 每个汉字算一个音。`-` 连字，`_` 延长，`/` 跳过，`{}` 组字。只保留第 1 段 |
| `"Am"` 与裸写的 `F`、`G7` 和弦记号 | 第一声部上的写进和弦标记（chordSymbols）；第二声部上的和认不出的列入丢失 |
| 反复、跳房子、注释文字、`X` 无音高节奏音、`Z` 多小节休止 | 列入丢失（多小节休止会展开成休止小节） |
| 无法识别的字符 | 跳过并列入丢失；整首没有音符时拒绝 |


## 123 简谱导出（`j123-export.ts`）

导出结果用谱线自己的 123 导入器读回。测试检查途中速度、拍号、转调、延长记号和渐快/渐慢在往返后等价（外部文本 → Score → 外部文本 → Score，含《匈牙利狂想曲第二号》）。不保证字节完全相同。

- 头字段写 `%123-1.0`、`T:`、`C:`（词曲）、`K:1=X` 或小调 `K:6=X`、`M:`、`Q:1/4=`。
- 途中变化写成行内 `[Q:1/4=]`、`[M:]`、`[K:]`；延长写成 `!fermata!`；渐慢/渐快写成 `"^rit."` / `"^accel."`（可带 `=目标速度`），区间结束处若没有新的途中速度则写 `"^a tempo"`。
- 第二声部写在 `V:2`。时值按 123 的减半、附点和多连音写出；必要时把长音拆开并用 `~` 连接，读回仍按时间对齐。

**写不进去、会在导出前列出的内容：** 第三声部起、反复与跳转、和弦标记、倚音、圆滑线、个别无法精确表示的时值。

## 番茄简谱导入（`fanqie-import.ts`）

规格来自 Dolce `docs/实现/文本谱.md`、`docs/模块/源格式-文本谱.md`、`src/fanqie/dialect.ts`，只实现番茄方言。

| 内容 | 结果 |
| --- | --- |
| `V: B: Z: D: P: J:` 头字段 | 保留标题、调、拍、速度；作者和速度说明列入丢失 |
| 后缀 `'` `,` `/` `.` `#` `$` `=`、`-` 延长、`0` 休止、`8` 隐藏休止 | 保留，升降号在同一小节内按级数沿用 |
| `( )` 圆滑线、`(y` 连音 | 保留；同音圆滑线合并为长音 |
| `&mf` `&zy` `&dy` `&bc` `&tr`、`< > !` 渐强渐弱 | 映射为力度、奏法、装饰音、渐强渐弱 |
| `&yc` `&ycy` 延长，`&rit` `&rall` `&accel` 与 `&tempo` / `&atempo` | 延长写进 fermatas；rit./accel. 写进 gradualTempos，不再列入丢失 |
| `1[2]` 倚音 | 保留为倚音；后倚音 `[h2]` 列入丢失 |
| `Q:` / `Q1:` / `Q2:` 曲行 | Q/Q1 进声部一，Q2 进 voice2；Q3 起列入丢失 |
| `C:` / `C1:` 歌词 | 跟随最近的曲行。`/` 分词，`@` 跳过，`~` 连字。只保留第 1 段 |
| `"p:2/4"` `"k:2"` 临时变拍/变调 | 写进 changes |
| `"hx:Am"` 和弦记号 | 写进和弦标记（chordSymbols），规则同 123 |
| 反复、跳房子、`{bz…}` 等图层 | 列入丢失 |

**诗歌本方言**（`T: XL: FontSize:` 和 `1=C` 这类头部）能被识别，但会被拒绝并提示。它和番茄方言的语法不兼容，这一轮没有找到足够完整的公开规格，暂不实现。

## MusicXML 与 MIDI 的丢失清单

- **MusicXML：** 第一个声部之外的乐器部分、第三声部起、反复/跳房子/segno/coda、第 2 段起的歌词、踏板、延长记号、不琶音括号（non-arpeggiate；`<arpeggiate/>` 读成和弦上的琶音装饰）、滑音、震音、换气、文字与排练号、其他装饰音和力度、叠加的圆滑线、不完整的延音线、提示音、无音高音、超出上限的和弦音、C 谱号、落在休止/和弦/延音线上的歌词等。
- **MIDI：** 没有导入的其他声部、打击乐通道 10、踏板（CC64/66/67）、弯音、内嵌歌词、按键轻重差异、量化时丢弃或截短的音、同时超过 4 个音的和弦音。
