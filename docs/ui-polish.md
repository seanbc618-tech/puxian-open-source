# 网页界面整理（Approach A）

谱面优先：顶部只留品牌和「写谱」入口，谱面、写谱常显；表情、歌词、移调与乐器、风格、打印与导出、听写、本机草稿各自折叠成组。使用原生 details，键盘可展开；内容不卸载，保留输入、音频和导出引用。

底部固定播放／停止、撤销、重做，继续使用原有操作和禁用条件。手机避开安全区，正文留出底栏空间；桌面底栏居中，工具面板有更宽的操作空间。先看谱，再写音，再按需展开工具。

明亮浅色背景，保留奶油纸色 #f7f3ea、深墨和绿色强调色；按钮、字段样式与 Zone 提取到共享文件。网页 theme-color 与 PWA 生成器统一奶油色。标题缩短，分区说明藏在「了解更多」。

范围外：原生外壳、Capacitor、商店打包、深色模式、音乐核心改动、数据迁移。歌词／片段、第二声部、打印就绪检查、撤销和草稿、MIDI／MusicXML／图片导出沿用现有逻辑。
