# 三个及更多独立声部

谱线支持 1–16 个独立节奏声部。谱面下方可逐个添加、切换或删除声部。
文本、键盘、选音、改编和单声部听写只修改目标声部。删除可撤销，其他声部保留。
各声部保有自己的和弦、休止和时值；短声部只在排版/播放时补空白，草稿不写入补齐休止。

旧草稿继续使用 `notes` 与可选 `voice2`，第 3–16 声部为
`extraVoices: ScoreNote[][]`。有 extraVoices 时必须有 voice2；存储入口校验列表及上限。
简谱、五线、卷帘、六线、打印、音域检查、练习跟随、移调、分享与播放遍历全部声部。
现有八项功能栏、主工作区、奶油色、纯静态构建与 Capacitor 配置保持原有行为。

## MusicXML

每个声部写入独立 voice/staff 与谱号，用 backup 保持各自节奏。
导入保留首个有音分谱内最多 16 个 voice/staff 时间线；其余分谱与超限声部仍列损失清单。
谱线的 3+ 声部导出在标准 miscellaneous-field 中注明独立声部数量，以便空声部往返；
该字段不保存音符副本，实际音符均为标准 MusicXML note。其他软件不支持该字段时可忽略。

## MIDI

每个声部导出独立轨道，避开打击乐通道 10；第 16 声部使用另一 MIDI port。
PPQ 从 480 起按所需时值精度提高，超出标准 PPQ 上限时明确拒绝，避免静默量化。
「听写与音频」新增「预览全部声部导入」：严格解析后预览数量与损失，
确认才整谱替换，可撤销；原来的单轨选择及增强/双手量化保留。
全声部导入按原始 tick 保留各轨/通道的独立时间线，不沿用单轨导入的四音上限。
轨内音符交叠会拆成和弦事件，持续音可能重新起音；超八音、音域外音符、踏板等均报告损失。
MIDI 不表达全部谱面记号，完整记谱交换请用 MusicXML。

## 验证

`npm test` 包含四声部编辑隔离、播放跟随、简谱/五线命中、移调、
MusicXML/MIDI 往返、空声部、十六声部通道、七连音精度、分享/存储与音域等回归。
`node scripts/verify-voices.mjs` 在 Chromium/Firefox 实测添加四声部、编辑第三声部、
撤销、删除/恢复、草稿重载、简谱与五线切换，并拦截外部请求。
另外执行 typecheck、build:static 与原有 verify:static，保留 48 组 P2 与 Firefox 检查。
