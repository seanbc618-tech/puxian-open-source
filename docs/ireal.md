# iReal Pro 和弦谱导入（r20）

吸收自 iReal Pro：大量乐手在论坛与歌单里互相分享和弦谱，分享形式是一条 `irealb://` 链接（或导出的 `.html` 歌单网页，里面就是这种链接）。谱线只借鉴「贴一条链接就得到整首和弦进行、能直接放出来练」的做法，链接格式按社区公开的说明自己实现，没有使用任何上游代码、品牌或素材。

## 用法

写谱 → 导入区的「粘贴 … 文本」框里贴入链接（或整段网页源码），点「导入粘贴的文本」；也可以用「导入 123 / 番茄 / JP-Word / ABC」选 iReal 导出的 `.html` 文件。导入会替换整谱，是一步撤销，结束后列出导入说明与丢失项。读不懂的链接直接拒绝，现有谱不改。

解析器在独立懒加载块 `ireal-*.js`（约 8 KB）里，只在文本里出现 `irealb://` 时才下载；编辑器块只多了一行识别正则与登记项，首屏不变。

## 读进来什么

| iReal | 谱线 |
| --- | --- |
| 标题、作曲、调（`Eb`、`C-` 为小调）、速度 | 标题、调与调式、速度（0 时用 ♩=120，超出 40–220 夹到边界并记损失）；作曲与风格写进导入说明 |
| 和弦（`C^7`、`D-7`、`Bh7`、`C#o7`、`Eb-^7`、`D*m*`、`C7/E` …） | 和弦标记（`Cmaj7`、`Dm7`、`Bm7b5`、`C#dim7`、`EbmMaj7`、`Dm`、`C7/E`），同时在声部 1 写成密集排列的柱式和弦（最低音落在 G3–F#4，斜线低音放在下面），能直接播放 |
| 小节里的格子（和弦、空格、`p`、`W`；逗号只作分隔） | 按格子数分配时值，对齐到十六分音符 |
| `x` / `Kcl`、`r` | 重复上一小节 / 上两小节（不再重复写和弦名） |
| `n`（N.C.） | 休止 |
| `T44`、`T34`、`T68`、`T12` … | 拍号；中途换拍号写成变化 |
| `{ … }`、`N1` / `N2` | 反复与第一、第二结尾（第三结尾记损失） |
| `S`、`Q`（第一个是 To Coda，第二个是 Coda）、`<Fine>`、`<D.C. al …>`、`<D.S. al …>` | 跳转记号；有 Coda 却没写 D.C. 时，按 iReal 的习惯补一个 D.C. al Coda 并在说明里写明 |

## 丢失清单

括号里的替代和弦、其余注释文字（`<Solo break>` 等）、读不懂的记号与和弦（沿用前一个和弦）、谱线反复/跳转模型放不下的组合（例如 Fine 在反复段中间）。歌单里有多首时只导入第一首，说明里写出歌单名与首数。段落标记 `*A`、行距 `Y`、大小号 `s`/`l`、结尾 `U`、延长 `f` 不影响播放，直接略过。

## 测试

- `src/lib/music/ireal.test.ts`：解扰可逆、链接与歌单解析、和弦名换写与柱式排列、格子时值、重复小节、反复与结尾、换拍号、跳转、丢失清单、文本格式登记。
- `scripts/verify-ireal.mjs`（`verify:static` 内）：粘贴 123 不下载 iReal 块；粘贴链接后整谱替换、和弦标记、柱式和弦、反复、说明与损失；一步撤销；坏链接不改谱；390 宽不横向滚动。
