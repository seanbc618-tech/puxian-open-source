# 全屏演出与歌单

在谱面原有的「全屏看谱」中演出：点谱面左、右各三分之一，或按 ← / →、PageUp / PageDown 翻屏，每屏保留约 15% 重叠。未播放时空格也能翻屏；发送这些按键的蓝牙翻页器使用同一路径。中间区域不翻页，拖动仍能纵向滚动。全屏时谱面不选音、不放置输入光标，曲名只读；退出后恢复编辑。

「按速度自动滚」按乐谱总四分拍数与曲速估算时长，也累计曲中的速度变化。速度可调 50–150%，点「暂停滚屏」停止；手动翻屏、退出全屏会停止自动滚屏。播放期间自动滚屏让位给原有音符跟随。自动滚到末页会暂停，不自行切歌。

首页「我的曲子」区域的「歌单」按需加载。新建后选择本机曲子，使用上下按钮排序、移出曲子或删除歌单。打开歌单从第一首进入全屏；已经处于末页时再向后翻，复用本机草稿的打开流程进入下一首并回到顶部。顶端显示歌单名和当前序号，末首再翻停留在末首。退出全屏后仍保留本次歌单上下文，返回首页后结束。

数据使用 `puxian-setlists-v1`，只保存曲子 ID，不复制乐谱。读入时校验数据、去重并移除不存在的曲子；草稿删除或清理后同步清理歌单。歌单最多 100 个，名称最多 80 字。没有后端或新依赖。
