# Step E：只读 JP-Word `.jpwabc`

选择 JP-Word：补中文桌面简谱教育圈存量文件及 UTF-16LE 互通缺口，与 #16 简谱 SVG、#19 jianpu-ly 写出互补。Dolce 的格式文档和解析模型确认其独立格式与编码；“存量最大”没有独立统计，不能据此承诺覆盖率。123 是 Dolce 自有 UTF-8 主格式，优先级低于既有桌面文件；番茄也有存量，但本轮只选一种，不引入 OctoPus 等 GPL 代码。

输入为 UTF-16LE+BOM 字节，或已经正确解码的字符串。文件字节不回退 UTF-8，误开有中文错误。标题段读取 Title、KeyAndMeters、Expression；缺省 C、4/4、120，并提示。数字 0–7、升降还原、逗号/单引号八度、减时线、增时线和附点映射到实际 MIDI 音高与四分音符时值。B / bB 的无点主音在第三八度；#B 归一化为 C4（MIDI 60），bC 归一化为 B3（MIDI 59），其余在第四八度。单声部整谱替换；失败不 publish。

| 内容 | 结果与损失 |
| --- | --- |
| 标题、初始调/拍/速度 | 保留；非数字速度表情提示丢失 |
| 数字音符、休止、附点、八度、临时变音 | 保留；还原按音名字母自然音计算 |
| W1、W1-n、@小节,音符、分组与 / | 首段逐音歌词；休止占歌词槽且须以 / 跳过；/ 与文字均消费歌词槽，重复占用拒绝；$ 按行末小节收尾，曲中换行导致歧义或重叠时拒绝，无法对齐报错 |
| 第二/第三声部 | 格式原生单声部，无 voice2；重复 Voice 拒绝，避免静默丢旋律 |
| 反复、Repeat 演唱顺序 | 只读谱面一次，中文警告，不展开 |
| 多段歌词 | 只保留第一段，中文警告 |
| 连线、排版、署名、控制串 | 不保留，中文警告 |
| 和弦、倚音、连音组、曲中转调/转拍、未知音乐 token | 拒绝导入，保留现有谱 |
| 导出、123、番茄 | 已在 Step E2 补齐，见 [简谱文本互通](text-formats.md)；字节级往返、壳与 OMR 仍不做 |
