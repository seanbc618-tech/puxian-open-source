# 摇摆节奏（播放时值）

谱线在「移调与乐器」里提供三种八分音符摇摆：直拍、轻摆、摇摆。想法来自 GarageBand 钢琴卷帘的 Time Quantize / Swing：把一拍里两个八分音符的时值拉成前长后短，谱面写法本身不变。

- 直拍：对半分（50 / 50），也就是原来的均分八分。
- 轻摆：约 60 / 40。
- 摇摆：三连音比例（2/3 + 1/3）。

只作用在拍号分母为 2 或 4 的简单拍上。6/8 这类复合拍本身已有前长后短的拍感，仍按原谱播放。节拍器与预备拍始终打在正拍上，循环段落的长度也不变，高亮跟随会按实际听到的时值对齐。

选择记在本机 `puxian-swing-v1`，不写进谱子，也不改导出。播放中改摇摆，会从当前位置接着放、不重打预备拍。
