# 段落标记（r21）

吸收自 TT作曲家一类简谱打谱软件：在段落开头印一个醒目的标题（【前奏】【主歌】【副歌】【间奏】【尾声】，或 A / B / C、自定义短词），方便翻谱和对着唱。只借鉴这个排版与编辑习惯，没有使用任何上游代码、品牌或素材。

## 用法

写谱 →「段落标记」：先在谱上点一个音，再点前奏 / 主歌 / 副歌等（或输入最多 12 字再点「加上」）。标记落在该音所在小节的开头；再点同一小节会替换，点「清除标记」只去掉这一处。每次改动是一步撤销。

屏幕简谱与打印简谱在该小节左上角画【标记】。草稿、分享链接、MusicXML 会一起保存。

## 导入导出

| 格式 | 行为 |
| --- | --- |
| MusicXML | 读、写 `<direction-type><rehearsal>`；普通 `<words>` 仍列入「谱上文字」丢失项 |
| 123 | 行内 `[P:主歌]` 读成标记；`[P:AABA]` 这类演唱顺序仍记丢失（谱线没有唱段排队） |
| ABC | 行内 `[P:前奏]` 或字段 `P:` 读入，导出写回 `[P:…]` |
| JP-Word | 导出时列入丢失清单（该格式写不出段落标题） |

歌单里改旋律时，标记跟着原来所在的音走；超出新长度的会丢掉并提示，可撤销。选段重复时，段里的标记一并复制并后移。

面板是独立懒加载块，只在打开「写谱」时下载；首屏体积不变。
