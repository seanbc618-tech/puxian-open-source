# 词曲作者与简谱小节号

吸收对象是武汉风雅软件的「作曲大师 / 音乐梦想家」出版简谱排版习惯，只取功能思路，没有用它的代码、品牌或素材。

- 产品站：https://www.zuoqu.com/
- 产品中心：https://www.zuoqu.com/chanpinzhongxin/

## 词、曲

谱面可记下可选的词作者、曲作者（各最多 40 字）。屏幕标题下方用「词：…　曲：…」显示；打印简谱把「词：…」放在标题行左侧、「曲：…」放在右侧，不另占一行，所以页眉高度 `firstHeaderPx` 不变。写谱面板里可以填写或清除。

MusicXML 读写 `<identification><creator type="composer|lyricist">`；123 与 ABC 读写 `C:` 行（`词：… 曲：…`，或单独一个名字当作曲作者）。JP-Word 导出仍会记下「词曲署名」为损失项。

五线谱标题没有改，也没有改 `notation.ts` / 首屏。

## 小节号

简谱屏幕和打印都会在每个小节开头标出小号的小节号，不进谱面数据模型。段落标记若在同一小节，打印里仍在更靠上的位置（yBase+2），小节号在其下（yBase+12）。五线谱不标小节号。
