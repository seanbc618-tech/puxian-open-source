# 本机混音台与播放音色

在播放条打开「练习」，可按声部设置音量（0–100%）、静音 M、独奏 S、左右声像（−100 到 100）和音色。功能栏仍为八项。混音台按曲记住设置，只保存在本机 `puxian-mixer-v1`，最多保留最近 50 曲。不会写入 Score、草稿、分享、MusicXML 或其他乐谱导出。

声音先经过分手练：另一手静音时不会发声，小声伴奏时增益乘 0.3；之后再乘混音台音量。任一声部独奏时只听独奏声部，静音优先于独奏，因此独奏不会让被分手练过滤的声部重新发声。谱面跟奏仍跟随分手练的事件与时间，不因混音静音改变。节拍器和预备拍保持独立。

播放时修改设置，在下一次播放生效；等你弹的「听当前音」使用当前设置。增添声部使用默认值，删除声部同步移除对应行；撤销乐谱删除后恢复的声部使用默认混音设置。非法存储字段丢弃，缺失行补默认，多余行截掉。存储受限时仍可在当前会话使用。

六种声音均为原创 Web Audio 正弦谐波、包络和低通滤波合成：钢琴（默认，保留原来的谐波与衰减）、柔和电钢、弦乐、长笛、拨弦（吉他）、贝斯。普通播放、试听、循环慢练、变速续播、渐进加速和等你弹提示音共用同一合成器。声像使用 StereoPannerNode；缺失该能力时忽略声像、正常发声。无需网络、采样音色库或新依赖。合成音色为轻量近似，不承诺采样乐器的真实感。

MIDI 例外：只有用户主动选择过音色的声部，才在轨道开头写 GM program（从 0 开始）：钢琴 0、电钢 4、弦乐 48、长笛 73、尼龙吉他 24、贝斯 33。主动选回钢琴会写 0；从未选择过音色的旧曲不增加 program，原始 MIDI 输出不变。混音音量、静音、独奏和声像不写入 MIDI。严格解析器可通过 `listMidiVoices` 的可选 `program` 字段读取初始 program；导入乐谱仍不把播放偏好写入 Score。
