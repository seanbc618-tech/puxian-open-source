# 第 15 轮：选段编辑（吸收 Sibelius 思路）+ 练习面板 390 宽收短 + 持续音计时

来源（只取功能思路，不用代码、品牌、素材）：
- https://resources.avid.com/SupportFiles/Sibelius/2024.10/Sibelius_Reference.pdf（"Repeating Selections"：R 把选区接在后面复制一遍，可以连按）
- https://www.scoringnotes.com/tips/command-and-control-in-sibelius/（↑/↓ 按调内音阶级进移动，Ctrl/⌘+↑/↓ 移八度）

## 用户能看到的
- 「表情记号」里，选中的音下面新增「选段编辑」，共 6 个按钮：重复一遍、上移一级、下移一级、高八度、低八度、改成休止。手机直接点按钮。
- 电脑上，选中音后可以用快捷键：R 重复，↑/↓ 一级，Ctrl/⌘+↑/↓ 八度。在曲名、文本框、下拉框里打字时不会触发；全屏看谱时方向键仍是翻页。
- 每次编辑都是一步撤销（Ctrl+Z）。
- 「重复一遍」：复制的那一遍紧接在原段后面，并自动选中，所以可以连按 R。
  - 歌词不复制（下一遍通常换词）。
  - 只有一个声部有时值时，段内的和弦名跟着复制，后面的和弦名、反复记号、跳转记号整体后移。
  - 判断规则：开启一段音乐的记号（|:、一房、Segno、Coda）正好落在段尾时跟后面一起移；收尾的记号（:|、Fine、To Coda、D.C.、D.S.）正好在段尾时留在原处。
  - 后面有反复或跳转记号、而选的又不是整小节时，拒绝并提示，以免记号错位。
  - 其他声部也有时值时，只改正在编辑的声部（和插入音的现有做法一致）。
- 「上移一级 / 下移一级」：按所在位置的调走调内音阶（有转调时取段首那个调）；调外音就近落到下一个调内音。倚音一起移。和弦的指法在音数变了时清掉。超出钢琴音域时拒绝。
- 「改成休止」：时值不变，去掉音高、记号、指法和歌词；连线、渐强渐弱只剩一头时一并去掉。
- 纯函数放在 `src/lib/music/selection-edit.ts`，单测见 `selection-edit.test.ts`；浏览器检查见 `scripts/verify-selection-edit.mjs`（390 和 1280 两种宽度）。

## 练习面板 390 宽收短（1956 → 约 1628 px，全部收起时）
- 四个小工具（独立节拍器、听音练耳、拍节奏、持续音）放进「小工具」一组，2 × 2 排列（宽屏 4 列），每格有名字和一行说明。再点一下收起，打开的工具显示在这组下面。
- 混音台：只有一个声部且没调过时，收成一行「单声部：钢琴音色，音量 100%，居中」加「展开混音台」按钮。多声部，或调过任何一项时照常展开。
- 面板底部那段说明收进「了解更多」。
- 新增检查：2 × 2 排列、每格 ≥ 44 px、单声部时混音台收起、390 宽面板全收起时 ≤ 1700 px。

## 持续音计入练琴时长（Sean 的决定）
- 持续音发声时算这首曲子的练琴时间，和独立节拍器一样。
- 和播谱、节拍器、拍节奏同时进行时只算一份。验证：持续音和节拍器同时响约 2 秒，当天总时长等于这首曲子的时长。
