# 公开示例里的公有领域世界名曲

首页「示例曲目」在五首短曲之后列出世界名曲。目录元数据留在首页模块；完整谱按曲目懒加载，不进入首屏。

谱线没有「升C」调名。月光奏鸣曲第一乐章与匈牙利狂想曲第二号在内部记为降 D 小调（与升 C 小调等音），首页列表写成「升C 小调」，简谱主音音高仍是升 C。

## 未收录

未找到可靠、可再分发的公有领域完整谱（或不愿把 CC BY-SA 的大型乐队总谱硬拆进谱线）的曲目，按任务要求跳过，不手敲音符：

- 春（维瓦尔第《四季》第一乐章）：Mutopia 仅有 LilyPond 分谱（CC BY-SA 3.0），没有现成 MusicXML/MIDI
- 自新大陆交响曲第二乐章：同上，Mutopia 为管弦乐总谱 LilyPond（CC BY-SA 3.0）
- G 弦上的咏叹调：推荐列表与 C 大调前奏曲为「或」；Mutopia 管弦乐版为 CC BY-SA，长笛与吉他改编虽为公有领域但不适合作为展示版本
- 匈牙利舞曲第五号、天鹅、天鹅湖场景、花之圆舞曲：Mutopia 与已核过的 Noctave 公有领域目录中没有可靠完整谱
- 《克罗地亚狂想曲》：仍在版权保护期，按要求不收录
- 二泉映月：未采用手敲音符补谱，也没有既定、可再分发的完整公有领域谱
- 梁祝：何占豪、陈钢 1959 年作品，仍在版权保护期
- 义勇军进行曲：仍受著作权及相关使用限制，不收录
- 晚期拉赫玛尼诺夫：部分作品在不同法域的版权状态不一，按要求跳过
- 西贝柳斯（《芬兰颂》等）：作者 1957 年逝世，在作者死后 70 年的法域仍在保护期
- Piazzolla：作者 1992 年逝世，仍在版权保护期
- 不确定的 Gershwin 改编：底本与编配版权难以确认，不收录
