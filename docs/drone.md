# 第 14 轮：持续音（吸收 TonalEnergy Tuner 思路）

来源（只取功能思路，不用代码、品牌、素材）：
- https://apps.apple.com/us/app/tonalenergy-tuner-metronome/id497716362
- https://www.tonalenergy.com/te-mobile
（借鉴两点：一是持续音，可以是单音、和弦，跟着调走；二是平均律 / 纯律一键切换，纯律下和弦的三度、五度按整数比调准，听起来不打拍）

## 用户能看到的
- 练习面板新增「持续音（对着长音练音准）」，点开才加载，首屏不变（8 个请求 / 384,701 B）。
- 跟着乐谱的调走：根音默认是 1 级（主音，C3–B3 这一组），可以选 1–7 级。
- 声部：单音 / 根音 + 纯五度 / 调内三和弦（ii、iii、vi 是小三和弦，vii 是减三和弦，小调同理）。
- 律制：平均律（和钢琴、播放一致），或纯律（无拍音）。纯律会标出相对平均律差多少音分，例如大三度 −14 音分、纯五度 +2 音分。
- 音量滑杆。声部、律制、音量存在本机（`puxian-drone-v1`），根音级数不存。
- 声音是本机 Web Audio，正弦波加一点三角波高八度，淡入淡出。播放乐谱时持续音自动停；收起持续音或关掉练习面板时关闭 AudioContext。
- 持续音发声时计入当前曲子的练琴时长（第 15 轮，Sean 的决定），和其他计时源同时进行时不重复计。

## 实现
- `src/lib/music/drone.ts`：纯函数 `droneRoot`、`droneIntervals`、`droneFrequencies`、`justCents`，加上设置的读写；单测在 `drone.test.ts`。
- 踩坑：Tailwind 会扫源码注释里的单词，注释里写了 “ring” 就生成了 `.ring` 工具类，首屏 CSS 涨了 1.6 KB。已改掉措辞。以后注释里避开 ring、shadow、border 这类工具类名。

# 同轮：拍节奏延迟补偿
- 拍节奏卡片新增「延迟补偿 N 毫秒」：−/+ 每次 10 毫秒，范围 −100 到 400 毫秒，存在本机（`puxian-rhythm-latency-v1`）。
- 「点按校准」：每 0.6 秒响一声，共 8 声，每声点一下。去掉前 2 声热身后，每一声取 −150 到 +450 毫秒内最近的一次点按，算偏差的中位数。配上的少于 4 下就不改，并提示「点得太少」。
- 判定前，每次点按的时间先减去补偿值（`compensate`）；对照条显示的是补偿后的位置。
