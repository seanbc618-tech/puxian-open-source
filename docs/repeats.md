# 反复记号与一房、二房（第 7 轮）

参考了常见打谱软件（MuseScore、Flat、Noteflight 一类）的「反复小节线 + 跳房子」体验，只吸收功能与交互，不含任何对方代码、品牌或素材。

## 用法

写谱 → 「反复与跳房子」：先在谱上点一个音，按钮作用于这个音所在的小节。

- `|: 反复开始`：这一小节起反复（没有结束时先只反复这一小节）。
- `:| 反复结束`：这一小节末尾回到反复开始（前面没有 `|:` 时从头反复）。
- `一房 1.`：反复段里靠后的小节，第一遍走到这里，第二遍跳过。
- `二房 2.`：紧接 `:|` 后的小节，第二遍从这里接着奏；可以延伸几个小节。
- `清除反复`：删掉这一小节所在的反复。

摘要行用小节号说明当前反复；每一步都能撤销。不合理的设置（重叠、一房在段外、二房没紧接）会用中文说明原因，谱不变。

## 数据

`Score.repeats?: { from; to; ending?; endingEnd? }[]`，单位为四分音符拍，都落在小节线上；不嵌套、不重叠、按顺序排列。`|: A [1 B :| [2 C` 展开为 A B A C。旧谱没有这个字段，行为不变。

## 各处的表现

| 位置 | 行为 |
| --- | --- |
| 五线谱 | ABC 小节线 `|:`、`:|`、`[1`、`[2`，abcjs 画反复点与房子括号 |
| 简谱（屏幕 / 打印） | 粗细双线 + 反复点，1. / 2. 房子括号 |
| 播放、高亮、跟随 | 按展开顺序播放；高亮映射回原谱中的音，暂停后从展开位置继续 |
| 练习循环 | 设了循环区间时按谱面顺序奏这一段，不展开 |
| 等待模式 | 没设区间时按展开顺序等待 |
| MIDI 导出 | 写入展开后的音 |
| MusicXML | 导出 `<barline>` 的 `repeat` / `ending`；导入时还原，能还原时不再列为丢失 |
| 分享链接、本机草稿 | 随谱保存；`isScore` 校验字段形状 |
| 改音 | 只改一个声部时，反复位置随后面的音移动；落在被改区间里的反复会去掉 |

## 体积

`repeats.ts` 单独成块（约 6.4 KB），随编辑器一起按需加载，首页不加载；首屏 8 个请求 / 385,543 B，低于合入前 main 的 386,421 B（编辑器用的练习文字拆到 `practice-text.ts`）。

## 检查

- `src/lib/music/repeats.test.ts`：展开、校验、编辑、移位、分享、MIDI、MusicXML 往返、等待模式、ABC。
- `scripts/verify-repeats.mjs`（并入 `verify:static`）：浏览器里逐个按钮设反复、错误提示、简谱与五线谱画出记号、播放高亮顺序 0 1 2 3 0 1 4 5 6 7、清除与撤销。

# 跳转记号：D.C. / D.S. / Fine / Coda（第 8 轮）

参考打谱软件（MuseScore「Repeats & jumps」、Dorico 的 jumps/markers 一类）的跳转体验，只吸收功能与交互。

## 用法

写谱 →「反复与跳房子」第二排，同样按选中音所在的小节：

- `D.C. 回开头` / `D.S. 回记号`：放在要跳回的小节末尾（两者只能有一个，后设的替换前一个）。
- `Segno 记号`：D.S. 跳回的地方（小节开头）。
- `Fine 结束`：跳回后奏到这个小节末尾结束（al Fine）。
- `To Coda` + `Coda 尾声`：跳回后奏到 To Coda 所在小节末尾，跳到 Coda 小节接着奏到结尾（al Coda）。Fine 与 Coda 只能选一种，后设的替换。
- 同一位置再点一次同一按钮可去掉；`清除跳转` 全部去掉；都能撤销。

摘要行用小节号说明跳转路线；不完整（例如 D.S. 没有 Segno、To Coda 没有 Coda）时写明「还不能跳转：…」，此时记号照画，播放按谱面不跳。跳转记号不能放在反复段中间（可放在两端）；之后加的反复把记号包进中间时，这个记号会去掉（可撤销）。

## 播放顺序

第一遍按反复正常奏到 D.C./D.S.；跳回后不再反复，只走最后一房（常规做法）；到 Fine 结束，或到 To Coda 跳到 Coda 奏完。

## 数据与各处

`Score.jumps?: { segno?; coda?; fine?; toCoda?; dc?; ds? }`（四分拍，落在小节线上）。

| 位置 | 行为 |
| --- | --- |
| 五线谱 | abcjs 装饰：`!segno!`、`!coda!` 在小节首音前；`!fine!`、`!coda!`（To Coda）、`!D.S.alcoda!` 等在小节线上；只画在第一声部 |
| 屏幕简谱 | Segno（画出的 S 斜线加两点）、⊕ Coda、Fine / To Coda / D.S. al Coda 文字；窄小节时上下错开，不叠字；首行自动让开 `1=X` 标题 |
| 打印简谱 | 第一声部小节上方文字标注 |
| 播放 / 高亮 / 等待模式 / MIDI | 同反复：按展开顺序，映射回原谱 |
| MusicXML | 导出 `<segno/>`、`<coda/>`、`<words>` 加 `<sound segno/coda/fine/tocoda/dacapo/dalsegno>`；导入读 `<sound>`，没有时读文字（D.C./D.S./Fine/To Coda）；能完整还原时不再列为丢失 |
| 分享链接 / 草稿 | 随谱保存，`isScore` 校验数值 |

体积：首屏 8 请求 / 384,826 B（合入前 main 385,543 B）——跳转逻辑在 `repeats` 懒加载块；`isScore` 多出的校验由把编辑器才用的 `loopFromBars` / `loopFromSelection` / `practiceChange` 移到 `practice-text.ts` 抵掉。
