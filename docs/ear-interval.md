# 听音程（练耳）

谱线在「练习 → 听音练耳」里，除了原来的认级数，还可以切到「认音程」。想法来自 musictheory.net / Tenuto 的 Interval Identification：弹出两个音，选出它们的音程，不改当前谱子。

- 范围：二三度（默认）、常见（大二、小三、大三、纯四、纯五、纯八）、全部（小二到纯八）。
- 听法：先后（默认）或同时。
- 选项用简写（小2、纯5、增4），完整名称在按钮的无障碍标签里。
- 对错记在本机 `puxian-ear-interval-v1`，与认级数的记录分开。时长仍计入听音练耳。
- 默认仍是认级数，原来的定调 + 级数练习不变。
