# Original GP5 fixture

`original-study.gp5` is an original one-bar test exercise created for Puxian,
not a commercial score or a transcription. The composition and generator are
released under CC0-1.0 (https://creativecommons.org/publicdomain/zero/1.0/).
Regenerate using `python3 src/lib/music/fixtures/gp5/generate.py`.

GP5 v5.00, 96 BPM, 4/4, standard guitar tuning, two voices:
upper B3/E4 dotted quarter brushed chord, hammer to F#4 eighth, half rest;
lower E2 whole note. Encoding is written directly using Python's standard library.
No third-party fixture or GPL/AGPL tooling is used or copied.
