# 本地几何识谱预览

这条预览把已经跑通强制集的离线几何路径（copisteria 检测 + `geom_from_dets` 谱线重建）接到和正式站同一套编辑器上，方便在本机上传谱图、查看音高和时值草稿。

- **不是**产品默认引擎，也 **不会**改线上站点。若本地 API 关闭，识别会退回原来的 SMT 本机路径。
- 本目录仍可用于本机跑识别接口。正式站文案已改为「本站识谱服务」；接口关闭时前端会退回浏览器内 SMT 后备路径。
- 服务默认只绑定 `127.0.0.1` 的高端口（默认 18095）。若以后要用手机在同一局域网查看，需要再改绑定，不要默认暴露到局域网。
- 不要占用本机已有的 Hiddify 端口，也不要改系统代理。

启动（在本机预览目录，已建好 venv 和权重之后）：

```sh
nohup ./preview/start-geom-preview.sh >/dev/null 2>&1 &
# 日志：logs/geom-preview.log
# 打开：http://127.0.0.1:18095/
```

用法：打开上述地址 →「识别图片」上传谱图 →「识别全部页并合并预览」→ 等待状态栏计时 →「编辑识别草稿」。检测在本机运行，大图可能需要一两分钟。

正式站部署、systemd 与 nginx 反代见仓库根目录 `docs/geom-omr-production.md`。不要把权重提交进 git。
